Class: module:objects/PhysicsObject

module:objects/PhysicsObject(label, vertices, colors, indices, normals, options)

Physics Scene object class, these objects have - simple gravity - movement velocity - rotational velocity - basic collisions (spheres atm)

new module:objects/PhysicsObject(label, vertices, colors, indices, normals, options)

Make a new PhysicsObject, a scene object with simple physics builtin

velocity number
rotVelocity number

hitboxRadius number the radius of this objects hitbox

onCollision function Callback function to call when this object collides with another collidable
