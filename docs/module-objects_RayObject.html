Class: module:objects/RayObject

module:objects/RayObject(label, type, options)

Raytracing Scene object class

Constructor

new module:objects/RayObject(label, type, options)

Make a new RayObject, a scene object meant to run in the hw7 based ray tracing fragment. Note that this object type is unique and does not rely on a mesh like all of our previous setup, it relies on the shader to construct the information at runtime. This also means that things like texture uvs, tangents etc will also have to be constructed at runtime. NOTE: Although a mesh should be usable in a ray tracer like this, consider checking the reflection for a triangle and just representing the reflection of a mesh as a triangle lookup then triangle reflection. NOTE: it could be reasonable to have all interaction with this type of object within the shader itself, but I like the structure of using shader as renderer and js as the logical control in webgl so I'll maintain that for now NOTE: js doesn't have multi class inheritance baked in so will be annoying to transfer the tiny changes in the physics object class for example. Can do something messy to accomplish it though..
