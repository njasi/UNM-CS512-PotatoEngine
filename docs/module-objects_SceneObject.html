Class: module:objects/SceneObject

module:objects/SceneObject(label, vertices, colors, indices, normals, options)

Wrapper class of a basic object to make animation and such simple. Represents the object properties - vertices - colors - indices - normals - texCoords - tangents Some meta properties: - label of the material to use when rendering the object - label of the shader program to use - list of renderpasses to use - lighting bounds for light culling And the current state of the object: - position - rotation - scale Additionally has a parent child relationship structure that can be leveraged to make a hiearchical model easily.
