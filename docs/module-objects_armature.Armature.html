Class: Armature

module:objects/armature.Armature(label)

Representation of internal armature of a model - bones, joints - important to allow for joint cycles unlike the bvh tree, as something like a chest loop is common (consider mediapipe model) - we can update the position of joints based on external update functions for example, after the bvh model has updated (which we already have) we can then use it to update the positions of all joints in the armature here. This shouldnt be notably expensive, and vaguely extensible to a different update function - should make a helper to turn bvh structure directly into an armature represenation and then map update function onto it...
