Class: module:renderers/CopyRenderPass

module:renderers/CopyRenderPass(label, optionsopt)

A simple render pass which copies from one target to another NOTE: composite / overlay etc type passes should be derivable from this structure composite probably just have two input textures and then all the hard work happens in the shader
