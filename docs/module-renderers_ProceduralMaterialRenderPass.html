Class: module:renderers/ProceduralMaterialRenderPass

module:renderers/ProceduralMaterialRenderPass(label, gl, programLabel, textureArray, options)

renderpass that is responsible for baking procedural materials into a Texture2DArray, which we can then reference in the ray.frag shader with a material descriptor pointing to a function with a index of above 127 this is a bit confusing sounding so see the example in examples/ray
