Class: module:renderers/RayRenderPass

module:renderers/RayRenderPass(label, options)

Wrapper class to help define render order and different types of objects Specifically this subclass handles a ray tracing type pass - additional list to tracks lights - TODO additional handling for textures - TODO additional handling for materials
