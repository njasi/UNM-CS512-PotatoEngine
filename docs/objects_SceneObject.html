Class: objects/SceneObject

objects/SceneObject(label, vertices, colors, indices, normals, options)

Wrapper class of a basic object to make animation and such simple. Represents the object properties - vertices - colors - indices - normals And the current state of the object: - position - rotation - scale Additionally has a parent child relationship structure that can be leveraged to make a hiearchical model easily.
