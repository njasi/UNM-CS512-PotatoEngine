Class: objects/loaders/BVHObject

objects/loaders/BVHObjectobjects/loaders/BVHObject()

Wrapper class for bvh objects. Only difference from a normal SceneObject is the rotation order property and the corresponding uniform note that the default value of the uniform is 0, prompting standard rotation order defined in the shader (XYZ), so we dont need to worry about this uniform in the SceneObject class and its children classes.
